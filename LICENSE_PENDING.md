# License decision required before the repository is public

The authors must choose a license for **original analysis code and original repository text**. A permissive code license such as BSD-3-Clause is commonly suitable for academic software, but the corresponding authors and institution must approve the final choice.

Do not apply that license to IHME/GBD data or other third-party material. IHME-derived content remains governed by the applicable IHME agreement. Natural Earth map geometry is public-domain material and retains its own provenance notice in `06_figures/assets/README.md`. Third-party software retains its own licenses.

Replace this file with the approved `LICENSE` before making the repository public or creating the archival DOI.
